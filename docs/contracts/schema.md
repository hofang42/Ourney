# Contract: data schema (v1.1)

Single source of truth shared by `supabase/migrations` (Postgres) and `apps/mobile/lib/data` (drift).
Changes go through a PR touching only this folder (owner: Architect/Orchestrator).
Since v1.1 the SQL in `supabase/migrations/0001..0004` is the server source of truth; this file
documents it (it wins only where the SQL contradicts `docs/SRS.md`).

## Enums
Wire values are the Postgres labels below (snake_case). Dart enums in `ourney_core` expose
`wireName` / `static fromWire(String)`; **never serialize with `Enum.name`**
(`TemplateId.weightLoss.name` is `weightLoss`, the wire value is `weight_loss`).

| Enum | Values | Dart |
|---|---|---|
| `journey_kind` | `solo`, `group` | `JourneyKind` |
| `journey_visibility` | `private`, `group`, `link` | `JourneyVisibility` |
| `journey_status` | `active`, `ended`, `archived` | `JourneyStatus` |
| `member_role` | `owner`, `member` | `MemberRole` |
| `member_status` | `active`, `left` | `MemberStatus` |
| `template_id` | `weight_loss`, `english_daily`, `workout_30`, `travel`, `custom` | `TemplateId` |
| `report_reason` | `spam`, `nudity`, `harassment`, `self_harm`, `other` | `ReportReason` |
| `reports.status` (text + CHECK) | `open`, `actioned`, `dismissed` | `ReportStatus` |

Visibility rules (table CHECKs): solo → `private` or `link`; group → always `group`; `link` only
for solo (FR-E3). `create_journey` raises `invalid` for group+`link` and solo+`group`, and
normalises group+`private` to `group`. Dart: `JourneyDraft.visibility` defaults to
`defaultVisibilityFor(kind)`; check with `validateJourneyVisibility(kind, visibility)`.

## Tables
All ids are UUID v4 generated by the client when created offline. All tables have `created_at timestamptz`, `updated_at timestamptz` (sync cursor, set by trigger) and `deleted_at timestamptz null` (soft delete) unless noted.

### profiles
| column | type | notes |
|---|---|---|
| id | uuid PK | = auth.users.id |
| username | text unique | 3–20 chars `[a-z0-9_.]` |
| display_name | text | 1–40 chars |
| avatar_path | text null | storage path `avatars/{user_id}/{uuid}.jpg` (`avatarPath()`) |

### journeys
| column | type | notes |
|---|---|---|
| id | uuid PK | |
| owner_id | uuid → profiles | moves to the earliest-joined active member when the owner leaves |
| kind | journey_kind | immutable |
| template_id | template_id | default `custom` |
| title | text | 1–60 chars |
| emoji | text | single emoji (≤ 16 code units) |
| metric_name | text null | ≤ 40, e.g. "Cân nặng" |
| metric_unit | text null | ≤ 16, e.g. "kg" |
| hide_metric_default | bool | true for weight_loss; copied to `memberships.hide_metric` on join |
| start_date | date | local date in `timezone`; immutable |
| duration_days | int null | 7..365, null = open |
| timezone | text | IANA, e.g. `Asia/Ho_Chi_Minh`; immutable |
| visibility | journey_visibility | see rules above |
| status | journey_status | default `active` |
| invite_code | text null unique | 8 chars `[A-Z0-9]`, group only, rotatable (`rotate_invite`) |
| max_members | int | 1..10, default 10; solo is always 1 |
| public_token | text null unique | **v1.1** 40 chars `[a-z0-9]`; non-null **iff** `visibility = link` (solo only). Revocable/rotatable via `set_public_link`. Dart: `Journey.publicToken` |

Clients may only `update` `title, emoji, metric_name, metric_unit, hide_metric_default, duration_days`
(owner, active journey). Everything else goes through RPCs.

### invites — **not a table**
Invites are `journeys.invite_code` only. Join with `join_by_code(code)` (also from the deep link
`ourney://join/<code>`); rotating the code invalidates the old one. No invite rows, no expiry.

### memberships
| column | type | notes |
|---|---|---|
| journey_id, user_id | PK | one row per (journey, user), kept after leaving |
| role | member_role | exactly one active `owner` per journey |
| status | member_status | `left` after leave/remove; rejoin sets `active` again |
| joined_at | timestamptz | personal progress counts from the journey-local date of this; kept on rejoin |
| hide_metric | bool | user-editable: hide my metric from others / public link |
| blur_media | bool | user-editable: blur my photos when shared outside |

Solo journeys have a membership too (the owner). Clients may only `update (hide_metric, blur_media)`
on their own active row. Dart: `Membership` (`JourneyRepository.watchMyMembership` /
`updateMyMembership`).

### check_ins
| column | type | notes |
|---|---|---|
| id | uuid PK | client generated |
| journey_id | uuid | |
| user_id | uuid | |
| local_date | date | server recomputes from `captured_at` + journey timezone (client value ignored) |
| captured_at | timestamptz | rejected if > now + 10 min (`invalid_captured_at`) |
| photo_path | text | `checkins/{journey_id}/{user_id}/{id}.jpg` (`checkInPhotoPath()`) — CHECKed |
| thumb_path | text | `checkins/{journey_id}/{user_id}/{id}_t.jpg` (`checkInThumbPath()`) — CHECKed |
| from_library | bool | |
| caption | text null | ≤ 140 chars |
| metric_value | numeric null | |
| hidden_by_leave | bool | **v1.1, server-managed** (clients cannot set it). True while the author has left the group; the row is also soft-deleted then and restored on rejoin. Not in the Dart model — treat it as any tombstone (`deleted_at`) |
| UNIQUE | (journey_id, user_id, local_date) | upsert target; retake replaces |

Writes fail with `ended` once the journey is not active or past its last day.

### reactions
`(checkin_id, user_id)` PK, `emoji text` (one of 🔥 💪 👏 ❤️ 😂, Dart `reactionEmojis`),
`created_at`, `updated_at`, `deleted_at` (**v1.1**). Direct `insert`/`update` by the reactor (no
delete grant): un-react = set `deleted_at`, re-react = upsert with `deleted_at = null`. Read-only once
the journey is not active (`ended`). Dart: `Reaction`.

### blocks
`(blocker_id, blocked_id)` PK, `created_at`, `updated_at`, `deleted_at` (**v1.1**; unblock = soft
delete). Read own rows only; write only via `block_user` / `unblock_user`.

### reports
`reports(id, reporter_id, target_checkin_id null, target_user_id null, reason report_reason,
note text null ≤ 500, status text default 'open' ∈ open|actioned|dismissed, created_at, updated_at,
deleted_at)`. Target FKs are `on delete set null`. Read own rows only; create only via `report_content`.

### moderation_queue (server-only, **v1.1**)
Never readable or writable through the API (deny-all RLS, no grants); service_role / dashboard only.
Filled by `report_content` (kind `report`) and `block_user` (kind `block`).

| column | type | notes |
|---|---|---|
| id | uuid PK | default gen_random_uuid() |
| kind | text | `report` \| `block` |
| report_id | uuid null → reports | cascade delete; null for blocks |
| actor_id | uuid null | reporter / blocker (no FK: evidence survives account deletion) |
| target_user_id | uuid null | no FK |
| target_checkin_id | uuid null | no FK |
| reason | report_reason null | reports only |
| note | text null | |
| status | text | `open` \| `actioned` \| `dismissed`, default `open` |
| handled_at | timestamptz null | |
| created_at, updated_at | timestamptz | no `deleted_at` |

## RPCs and Edge Functions
All RPCs are `SECURITY DEFINER`, require a signed-in user, and raise errors by message (see below).

| Server | Args → returns | Dart |
|---|---|---|
| `create_journey` | `p_id, p_kind, p_template_id, p_title, p_emoji, p_metric_name, p_metric_unit, p_hide_metric_default, p_start_date, p_duration_days, p_timezone, p_max_members=10, p_visibility='private'` → journeys row (idempotent on `p_id`) | `JourneyRepository.create` |
| `join_by_code` | `code` → journeys row (idempotent; rejoin restores) | `GroupRepository.joinByCode` |
| `rotate_invite` | `journey` → new code | `GroupRepository.rotateInviteCode` |
| `leave_journey` | `journey` | `GroupRepository.leave` |
| `remove_member` | `journey, member` | `GroupRepository.removeMember` |
| `end_journey` | `journey` → journeys row | `JourneyRepository.end` |
| `delete_journey` | `journey` (owner alone only; tombstones rows, client then deletes its own media) | `JourneyRepository.delete` |
| `set_public_link` | `journey, enabled` → token \| null | `JourneyRepository.setPublicLink` |
| `group_today` | `journey` → `(user_id, username, display_name, avatar_path, role, checked_in, checkin_id, thumb_path, captured_at, current_streak)` | `GroupRepository.watchToday` → `MemberToday` |
| `report_content` | `p_checkin, p_user, p_reason, p_note` → report id | `SafetyRepository.report` |
| `block_user` / `unblock_user` | `p_user` | `SafetyRepository.block` / `unblock` |
| `journey_streak` | `journey, member, today=null` → `(current_streak, best_streak, completed_days)` | `computeMemberStreak` (local mirror) |
| table upsert `check_ins` | on `(journey_id, user_id, local_date)` | `CheckInRepository.submit` |
| table upsert `reactions` | on `(checkin_id, user_id)` | `GroupRepository.react` / `unreact` |
| Edge `delete-account` | `POST`, user JWT | `AuthRepository.deleteAccount` |
| Edge `public-journey` | `GET ?token=<public_token>` → JSON (journey, streak, check-ins with signed URLs; metric/photos omitted per owner's `hide_metric`/`blur_media`) | `publicJourneyUri(supabaseUrl, token)` |

## Errors
Server error codes (exact strings) → Dart `OurneyErrorCode` (`fromWire`, `fromServer(message:, sqlstate:)`),
thrown as `OurneyException` (`JourneyLimitException`, `GroupException` are subclasses).

| Code | Source |
|---|---|
| `unauthenticated` | no JWT (SQLSTATE 28000); delete-account 401 |
| `forbidden` | not owner/member, deleted profile (42501; plain RLS denials are 42501 too) |
| `invalid` | bad arguments / combination (also generic 22xxx/23xxx, e.g. unknown timezone) |
| `not_found` | unknown id/code/token, invisible target; public-journey 404 |
| `full` | group has 10 active members |
| `blocked` | block in either direction with an active member |
| `limit` | 3 active journeys |
| `ended` | journey not active / past last day |
| `not_alone` | `delete_journey` with other active members (end it instead) |
| `rate_limited` | > 20 reports in 24 h |
| `immutable_column` | update of kind/timezone/start_date/id or check-in journey/user (23514) |
| `invalid_captured_at` | `captured_at` > now + 10 min (22008) |
| `method_not_allowed`, `storage_listing_failed`, `storage_cleanup_incomplete`, `storage_cleanup_failed`, `delete_failed`, `internal` | Edge Functions |
| `offline`, `unknown` | client-side only |

## Rules (enforced server-side; client mirrors for UX)
- Max **3 active journeys** per user (as owner or active member).
- Max **10 active members** per group journey.
- Streak: daily cadence, strict. See `streak_vectors.json`.
- **Late joiners**: a member's streak/progress window starts at
  `effectiveStreakStart(journey.startDate, joinedLocalDate)` = the later of the journey start and the
  journey-local date of `memberships.joined_at`; check-ins before that date are ignored; the window still
  ends at the journey end. Clients must use `computeMemberStreak(...)` (identical to `computeStreak`
  for solo owners) so local numbers equal `journey_streak` / `group_today.current_streak`.
- `local_date(captured_at, tz)` = calendar date of `captured_at` in `tz`.
- Group lifecycle: see `docs/02-requirements-v2.md` §9.1. Leave/remove hides the member's check-ins
  (soft delete + `hidden_by_leave`) and media; ownership passes to the earliest-joined active member;
  the journey is archived when nobody is left. Owner can delete only while alone, otherwise end.

## Storage
Bucket `media` (private). Paths above. Read allowed for own media, or if `is_member(journey_id)`, the
author is still an active member and neither blocked the other; write only to own `{user_id}` segment.
Signed URLs, TTL 1h; client caches by path.
