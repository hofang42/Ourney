# Contract: data schema (v1)

Single source of truth shared by `supabase/migrations` (Postgres) and `apps/mobile/lib/data` (drift).
Changes go through a PR touching only this folder (owner: Architect/Orchestrator).

## Enums
| Enum | Values |
|---|---|
| `journey_kind` | `solo`, `group` |
| `journey_visibility` | `private`, `group`, `link` (`link` only allowed when kind = `solo`) |
| `journey_status` | `active`, `ended`, `archived` |
| `member_role` | `owner`, `member` |

## Tables
All ids are UUID v4 generated by the client when created offline. All tables have `created_at timestamptz`, `updated_at timestamptz` (sync cursor) and `deleted_at timestamptz null` (soft delete) unless noted.

## Rules (enforced server-side; client mirrors for UX)
- Max **3 active journeys** per user (as owner or active member).
- Max **10 active members** per group journey.
- Streak: daily cadence, strict. See `streak_vectors.json`.
- `local_date(captured_at, tz)` = calendar date of `captured_at` in `tz`.
- Group lifecycle: see `docs/02-requirements-v2.md` §9.1.

## Storage
Bucket `media` (private). Paths above. Read allowed if `is_member(journey_id)`; write only to own `{user_id}` segment. Signed URLs, TTL 1h; client caches by path.
